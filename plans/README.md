## Findings Considered and Rejected

- **Building a Node/Express backend**: Rejected because BDS is a high-speed, lightweight static Vite landing site with direct client WhatsApp/phone lead capture; adding a Node server adds unnecessary hosting overhead and maintenance complexity.
- **Adding multi-page server rendering (Next.js/Remix migration)**: Rejected because the current React 19 + Vite hash-routing SPA is extremely fast, fully responsive, and provides instantaneous navigation without reload delays.
- **Replacing Canvas Confetti with heavier animation libraries (Lottie/Three.js)**: Rejected to preserve mobile performance and fast load times on regional 4G networks in East Godavari.
